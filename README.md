# Elena Belousova portfolio

Версия по документу `Сайт.docx` и уточнениям Егора от 29 сентября 2026. Опубликована на GitHub Pages; живой Wix-сайт не изменялся.

## Просмотр

Публичная версия: https://ikquwii.github.io/elena-wix-structural-clone/

Локальный просмотр:

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8766/ .

Основные ссылки: `#commercial`, `#fashion-weeks`, `#editorials`, `#about-contact`. Кнопка возле заголовка копирует адрес текущего сайта с якорем. Старые самостоятельные HTML-адреса перенаправляют на соответствующий раздел главной. Карточки Latest Projects открывают существующие страницы проектов исходного портфолио в новой вкладке.

## Состав

- Оригинальные фотографии, локально сжатые в WebP, без подмены порядка.
- 13 исходных галерей: 137 фотопозиций. Fashion Weeks — 14; Commercial — 14/16/15/23/11/5/6; Editorials — 4/6/5/4/14.
- 11 исходных карточек Latest Projects. На компьютере сохранена исходная композиция; на телефоне восстановлен вертикальный список с исходными пропорциями.
- Мобильная версия использует отдельно измеренную сетку Wix: разные размеры рядов, исходные серые/белые фоны и поля, перестроенный InStyle и два отдельных снимка между коллажами. Размеры масштабируются из исходной сетки 320 единиц на ширину телефона. Согласованные меню, тексты, ленты и About сохранены.
- Верхняя чёрная плашка удалена полностью. Описание публикаций находится на первом экране.
- Две бесконечные ленты изданий из Magazine. Фотокарусели конечные, без клонов.
- Новый About & Contact: слоган, прямоугольник под будущий портрет, согласованная биография; Based in → Phone → Instagram → Email.
- Избранного нет. Лёгкое увеличение фотографии внутри рамки, просмотр фотографий в диалоге, keyboard navigation и reduced motion.

## Известный пробел в исходных материалах

Сохранено 142 доступных уникальных изображения, включая дополнительный мобильный снимок. Один снимок исходного Wix CDN возвращает HTTP 403: 11-й кадр третьего коммерческого ряда (`comp-m5npdged`, item `8d77d49b-f1a0-4414-aaa7-b4ac2077d5bf`). В оригинальной галерее он также не загружается (`complete=true`, `naturalWidth=0`). Его место и номер сохранены с явной пометкой, соседней фотографией он не подменялся. Для заполнения нужен рабочий исходный файл. Это отдельно от согласованного прямоугольника под портрет Лены.

## Проверки и источники

```sh
sh tests/verify.sh
```

Проверки сверяют порядок и IDs с `source-manifest.json`, декодируют локальные изображения и проверяют структуру документа. Известная недоступная фотография выводится явным предупреждением; успешный структурный тест не означает полноту фотоматериалов. Результаты браузерных проверок — `QA.md`.

- `source-manifest.json` — источник каждого файла, порядок, исходные и оптимизированные размеры, ошибки загрузки.
- `scripts/prepare_assets.py` — повторяемое получение файлов из публичного источника; при недоступном файле завершает работу с ошибкой.
- `reference/mobile-source.json` — независимый снимок мобильной геометрии исходного Wix, поля, фоны и метаданные отдельных снимков; основание для генератора и браузерного сравнения.
- `tests/mobile-layout.cjs` — проверка реальных размеров и расположения в браузере против снимка Wix, вертикального Latest, согласованных добавлений, карусели и просмотрщика. Нужен установленный Playwright (или `PLAYWRIGHT_MODULE`); путь браузера можно задать через `PW_EXECUTABLE`, WebKit — через `QA_ENGINE=webkit`.
- `scripts/build_gallery_data.py` — размеры кадров и внешних контейнеров, сверенные при 1280px и 1710px, и генерация `gallery-data.js`. Фиксированные ряды следуют сетке Wix; растягивающиеся сохраняют свои боковые поля.
- `index.html`, `shell.css` — структура, типографика, hero, меню, ленты и контакты.
- `app.js`, `gallery.css` — галереи, просмотр, копирование ссылок и адаптивная раскладка.
- `image-loader.js` — ограниченные повторные попытки при временной ошибке загрузки фотографии; поведение проверяется `tests/image-loader.test.cjs`.

Старые `styles.css` и `pages.js` не подключаются к новой странице; оставлены в черновике как часть исходной заготовки.
