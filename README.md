# Elena Belousova portfolio prototype

Полная структурная копия длинной главной страницы личного портфолио Елены Белоусовой.

- исходный desktop-холст главной: `1280 × 13767 px`;
- 64 точно размеченные позиции исходного сайта;
- 7 бесконечных каруселей с 51 уникальным слайдом (14/14/5/4/5/4/5);
- управление кнопкой и горизонтальным жестом тачпада в обе стороны;
- 85 логических фотоплейсхолдеров; циклические копии скрыты от accessibility tree;
- реальные фотографии и Wix CDN не используются;
- фотослоты заменены 12 нейтральными оттенками;
- сохранены основные тексты, секции, пропорции и контактный футер;
- отдельные адреса: `commercial.html`, `editorials.html`, `fashion-weeks.html`, `about-contact.html`;
- Gallery Wall не используется: галереи сохраняют геометрию исходного Wix-сайта;
- на телефоне показывается отдельная асимметричная композиция, а не уменьшенная десктопная страница;
- Contact находится только на главной странице; About использует согласованный текст о Лене.

## Запуск

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8765/`.
