# Elena Belousova portfolio draft

Локальный черновик по документу `Сайт.docx` и уточнениям Егора от 29 сентября 2026. Живой Wix-сайт и исходная рабочая папка не изменялись. Черновик находится в отдельном worktree, ветка `codex/elena-portfolio-draft`.

## Просмотр

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8766/ . Это локальный просмотр; публикации в интернете нет.

Основные ссылки: `#commercial`, `#fashion-weeks`, `#editorials`, `#about-contact`. Кнопка возле заголовка копирует адрес текущего сайта с якорем. Старые самостоятельные HTML-адреса перенаправляют на соответствующий раздел главной. Карточки Latest Projects открывают существующие страницы проектов исходного портфолио в новой вкладке.

## Состав

- Оригинальные фотографии, локально сжатые в WebP, без подмены порядка.
- 13 исходных галерей: 137 фотопозиций. Fashion Weeks — 14; Commercial — 14/16/15/23/11/5/6; Editorials — 4/6/5/4/14.
- 11 исходных карточек Latest Projects. Desktop-композиция измерена по оригиналу; на телефоне — крупные свайп-карточки с адаптивной высотой.
- Верхняя чёрная плашка удалена полностью. Описание публикаций находится на первом экране.
- Две бесконечные ленты изданий из Magazine. Фотокарусели конечные, без клонов.
- Новый About & Contact: слоган, прямоугольник под будущий портрет, согласованная биография; Based in → Phone → Instagram → Email.
- Избранного нет. Лёгкое увеличение фотографии внутри рамки, просмотр фотографий в диалоге, keyboard navigation и reduced motion.

## Известный пробел в исходных материалах

Скачано 141 из 142 уникальных изображений, 9 378 244 байта. Один снимок исходного Wix CDN возвращает HTTP 403: 11-й кадр третьего коммерческого ряда (`comp-m5npdged`, item `8d77d49b-f1a0-4414-aaa7-b4ac2077d5bf`). В оригинальной галерее он также не загружается (`complete=true`, `naturalWidth=0`). Его место и номер сохранены с явной пометкой, соседней фотографией он не подменялся. Для заполнения нужен рабочий исходный файл. Это отдельно от согласованного прямоугольника под портрет Лены.

## Проверки и источники

```sh
sh tests/verify.sh
```

Проверки сверяют порядок и IDs с `source-manifest.json`, декодируют локальные изображения и проверяют структуру документа. Известная недоступная фотография выводится явным предупреждением; успешный структурный тест не означает полноту фотоматериалов. Результаты браузерных проверок — `QA.md`.

- `source-manifest.json` — источник каждого файла, порядок, исходные и оптимизированные размеры, ошибки загрузки.
- `scripts/prepare_assets.py` — повторяемое получение файлов из публичного источника; при недоступном файле завершает работу с ошибкой.
- `scripts/build_gallery_data.py` — измеренная геометрия при ширине 1280px и генерация `gallery-data.js`.
- `index.html`, `shell.css` — структура, типографика, hero, меню, ленты и контакты.
- `app.js`, `gallery.css` — галереи, просмотр, копирование ссылок и адаптивная раскладка.

Старые `styles.css` и `pages.js` не подключаются к новой странице; оставлены в черновике как часть исходной заготовки.
